# Linux deployment validation artifacts

This directory contains the frozen outputs associated with the final Linux-side ROS 2 / Fast DDS deployment validation.

Included material:

- Phase 10b canonical Ethernet soak;
- telemetry and summaries associated with the final V01/V02 captures.

The `video_final` directory contains telemetry only, not video files or rendered frames.

Intermediate discovery, networking and development phases are intentionally excluded from the final thesis repository.

`SHA256SUMS.txt` records integrity hashes for the preserved deployment sources, configuration and validation artifacts.
